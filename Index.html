Decision-Analytic Template (decisionSupport + R workflow)

Cory Whitney

Purpose and workflow

This repository is a template for collaborating on decision models in R using {decisionSupport}.

Workflow rule: the whole project should run by knitting index.Rmd.

Folder conventions:

data/ contains the uncertainty input table (inputs_decision.csv) and any raw data

scripts/ contains the model function and small helpers (local files)

figures/ stores exported figures (optional)

Local scripts used here:

  • scripts/make_variables.R
  • scripts/Decision_Model.R

Model testing (construction helper)

This chunk builds the variables from the input table so you can test pieces of the model interactively.

source("scripts/make_variables.R")
make_variables(decisionSupport::estimate_read_csv("data/inputs_decision.csv"))

Check that input variables appear in the model script

This catches a common issue: the CSV contains variables that never get used in the model.

data <- read.csv("data/inputs_decision.csv")
var_list <- unique(data$variable)
r_script_lines <- readLines("scripts/Decision_Model.R")
r_script_text <- paste(r_script_lines, collapse = " ")

missing_in_script <- var_list[!sapply(var_list, function(v) grepl(v, r_script_text, fixed = TRUE))]
missing_in_script
## character(0)

Monte Carlo simulation

Run the decision model under uncertainty with decisionSupport::mcSimulation().

source("scripts/Decision_Model.R")

set.seed(42) # from Deep Thought

decision_simulation_results <- mcSimulation(
  estimate = estimate_read_csv("data/inputs_decision.csv"),
  model_function = decision_function,
  numberOfModelRuns = 1e4,
  functionSyntax = "plainNames"

Cashflows over time

The model returns a vector Cashflow across years. In decisionSupport, vectors are expanded into columns like Cashflow1, Cashflow2, …

cashflow_cols <- grep("^Cashflow\\d+$", names(decision_simulation_results$y), value = TRUE)

cashflow_means <- tibble(
  year = seq_along(cashflow_cols),
  mean_cashflow = colMeans(decision_simulation_results$y[, cashflow_cols, drop = FALSE])
)

Notes for collaborators

Start simple: get the project structure correct and make sure index.Rmd knits cleanly.

Keep all key steps visible in index.Rmd:

  • read inputs
  • run simulation
  • summarize results
  • generate figures

Add complexity only after the baseline model is reproducible

  1. We will use basic ggplot2 functions for plotting in this example but there are a number of useful plotting options in {decisionSupport}. See the vignettes in the CRAN. ↩︎
